# CAD·3D모델링 마스터

2D CAD(AutoCAD)의 좌표·명령어·도면층부터 생산자동화기능사 CAD작업 도면 시트형식,
솔리드웍스 3D 모델링 피처까지 한 장으로 익히는 학습도구.

- 주소 : https://hongyul67-cpu.github.io/cad-3d-master/
- 대상 : 스마트팩토리(메카트로닉스)과 2·3학년 · 기초제도 「컴퓨터를 이용한 제도」 · 생산자동화기능사 CAD작업
- 만든 날 : 2026-09-04

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 배우기 8단원 → 게임 4종 → 연습 8문항 → 종합시험 20문항 → 오답노트 → 제출 |
| `rubric.json` | 결과수집이 세특 문장·성취수준을 만들 때 쓰는 평가 루브릭 (평가요소 5) |

### 배우기 8단원

Ⅰ. CAD 시작하기 · Ⅱ. 좌표와 그리기 · Ⅲ. 도면 편집하기 · Ⅳ. 해칭·문자·도면층 ·
Ⅴ. 치수 기입과 출력 · Ⅵ. 도면 시트형식(실기) · Ⅶ. 3D 모델링(솔리드웍스) · Ⅷ. 평가 기준

### 게임 4종

| 게임 | 하는 일 |
|---|---|
| 📐 좌표 입력 | 격자에 찍힌 두 점을 보고 절대·상대·상대극좌표를 가려 넣는다 (문제 자동 생성) |
| ⌨️ 명령어 찾기 | 하는 일을 보고 명령어를, 명령어를 보고 단축키를 고른다 (명령 57개) |
| 🎨 레이어 배정 | 윤곽선·외형선·숨은선·중심선 등 15가지를 6개 레이어에 배정한다 |
| 🧊 피처 고르기 | 스케치→형상 그림을 보고 어떤 피처를 썼는지 맞힌다 (피처 10종) |

## 원자료

전부 이 학교 수업 자료다. **교재·상용 도면을 저장소에 옮기지 않았고, 그림은 전부 SVG 로 직접 그렸다.**

| 자료 | 쓴 곳 |
|---|---|
| 「CAD 과정」 2D CAD(AutoCAD) 교재 111쪽 | Ⅰ~Ⅴ단원 개념 · 명령어 57개 · OSNAP 12옵션 · 좌표 예제 · Ⅷ 평가 기준 |
| 「기계요소 설계 (NCS) 워크북 (2D)」 208쪽 | 명령 지도 순서(LINE→ORTHO→CIRCLE→OSNAP→…→MTEXT) |
| 「도면 시트형식 만들기」(3학년 전자기계회로) | Ⅵ단원 전체 — A3 윤곽선 좌표·중심마크·표제란·레이어 6개 |
| 「2학년 솔리드웍스 1~8」 실습과제 | Ⅶ단원 차시 구성과 피처 주제 |
| 「기초제도 성취기준」 6. 컴퓨터를 이용한 제도 | `rubric.json` 의 성취기준·성취수준 (61-1 · 61-2 · 62-1 · 63-3) |

**넣지 않은 것** — 「생산자동화 기능사 CAD 실기 문제 모음」과 스터디캐드캠 도면 45장은
상용 사이트 워터마크가 박힌 자료라 저장소에 넣지 않았다. 그 도면들이 공통으로 요구하는
규칙(표제란 구성 · 주서 읽기 · 일반공차 ±0.1 · 일반모따기 C0.2 · 척도 · 3각법)만 개념으로 옮겼다.

`dist:공개` — 암호 잠금 없음.

## 고칠 곳

`index.html` 위쪽의 `LEARN`(개념 카드) · `QUESTIONS`(문항) · `CMDS`(명령어 사전) ·
`LAYERS`(레이어 규격) · `FEAT`(피처 그림) 배열만 고치면 됩니다.
게임 문제는 이 배열들에서 자동으로 만들어집니다.
