# CAD·3D모델링 마스터

2D CAD(AutoCAD)의 좌표·명령어·도면층부터 생산자동화기능사 CAD작업 도면 시트형식,
솔리드웍스 3D 모델링 피처까지 한 장으로 익히는 학습도구.

- 주소 : https://hongyul67-cpu.github.io/cad-3d-master/
- 대상 : 스마트팩토리(메카트로닉스)과 2·3학년 · 기초제도 「컴퓨터를 이용한 제도」 · 생산자동화기능사 CAD작업
- 만든 날 : 2026-09-04

## 구성

### 수업 슬라이드 (선생님용) — 44장

배우기 탭 위의 **📽️ 수업 슬라이드 열기** 로 엽니다.
화면은 `links` 저장소의 공용 뷰어(`board-pro.js`)라 이 저장소에 사본을 두지 않습니다.
✕ 나가기 · 🖱️선택 · 펜 · 형광펜 · 지우개 · 가리개 · 타이머 · 번호뽑기 · 전체화면이 붙어 있고,
한 장이 **요점 → 발문 → 퀴즈 → 정답** 순으로 클릭 한 번씩 열립니다.
요점 속 **파란 빈칸**은 눌러야 답이 보입니다.

| 단원 | 장수 | 단원 | 장수 |
|---|---|---|---|
| Ⅰ. CAD 시작하기 | 6 | Ⅴ. 치수 기입과 출력 | 4 |
| Ⅱ. 좌표와 그리기 | 5 | **Ⅵ. 도면 시트형식(실기)** | **10** |
| Ⅲ. 도면 편집하기 | 6 | Ⅶ. 3D 모델링(솔리드웍스) | 7 |
| Ⅳ. 해칭·문자·도면층 | 4 | Ⅷ. 평가 기준 | 2 |

**Ⅵ단원은 솔리드웍스 조작을 ①~⑩ 단계별로 한 장씩** 넘깁니다
(새 문서·A3 가로 → 3각법 → 윤곽선 좌표 → 중심마크 → 표제란 → 레이어 6개 →
시트형식 선 배정 → 도면 선 배정 → 시트형식 저장 → 주서).

**배우기 카드(46장)는 그대로 둡니다.** 슬라이드는 같은 내용을 교실 화면용으로
한 벌 더 만든 별도의 덱입니다. 그림은 `index.html` 이 이미 가진
`FIG`·`FEAT`·`layTable()` 을 그대로 불러 쓰고, 슬라이드에만 필요한 6개
(작업순서 · 윈도우/크로싱 · TRIM/EXTEND · ARRAY · 선형/정렬 치수 · 3D 순서)만
`lesson.js` 안에서 새로 그렸습니다.

규칙(표제란 구성 · 주서 읽기 · 일반공차 ±0.1 · 일반모따기 C0.2 · 척도 · 3각법)만 개념으로 옮겼다.

`dist:공개` — 암호 잠금 없음.

## 고칠 곳

`index.html` 위쪽의 `LEARN`(개념 카드) · `QUESTIONS`(문항) · `CMDS`(명령어 사전) ·
`LAYERS`(레이어 규격) · `FEAT`(피처 그림) 배열만 고치면 됩니다.
게임 문제는 이 배열들에서 자동으로 만들어집니다.

수업 슬라이드는 `lesson.js` 의 `LESSON` 배열입니다.
화면을 그리는 `board-pro.js` 는 `links` 저장소의 **공용 파일**이라 여기에 사본을 두지 않습니다 —
고칠 일이 생기면 `links` 쪽 한 곳만 고칩니다.
(떠 있는 위젯 가운데 🔇 소리(`#fxSnd`)만 이 도구가 `lesson.js` 안에서 가립니다.
 뒤로·기록 초기화·계급 배지·평가 기준은 공용 뷰어가 가립니다.)
